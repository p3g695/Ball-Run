# Ball Run 🏀

An endless 3D obstacle platformer game made with Three.js!

## How to Play
- **Arrow Keys / WASD**: Roll the ball left, right, forward, or backward.
- **Spacebar**: Jump over obstacles.
- **Pause Button**: Top-left corner to freeze gameplay.
- Hit **Checkpoints** to save your progression distance.
